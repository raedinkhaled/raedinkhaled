## About Me

I work across the full stack with a clear preference for the backend — designing APIs, modelling data, and building services that hold up in production. My main stack is Java with Spring Boot on one side and TypeScript with NestJS on the other, with MongoDB and PostgreSQL as my go-to databases. On the frontend I have worked with Angular and React in professional projects.

I care about clean architecture, maintainable code, and documentation that does not go out of date the moment it is written. I apply TDD as a regular part of development and take code reviews seriously — both giving and receiving them.

Alongside my development work, I am completing a **Master's in Artificial Intelligence at JKU Linz**, building on a prior M.Sc. in Data Engineering and Web Technologies. I use AI-assisted development tools (Claude Code, GitHub Copilot, Cursor) as a genuine part of my workflow — for code generation, review, testing, and documentation — not just as an occasional shortcut.
